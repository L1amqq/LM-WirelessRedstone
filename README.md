<h1><img src="common/src/main/resources/assets/lm_wireless_redstone/icon.png" width="40" alt=""> LM Wireless Redstone</h1>

Беспроводной редстоун для Minecraft без ограничения дальности сигнала.

**Fabric · NeoForge · Forge** для Minecraft **1.21.11 и 26.1–26.3**.

[**Скачать мод**](https://github.com/L1amqq/LM-WirelessRedstone/releases/latest)

Выберите JAR для своего загрузчика и версии Minecraft и поместите его в папку `mods`. Для Fabric также нужен Fabric API.

Чтобы связать блоки, нажмите осколком аметиста по передатчику, затем по приёмнику.
