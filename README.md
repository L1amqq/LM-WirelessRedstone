## Установка

Скачайте JAR для своей версии Minecraft и загрузчика из [последнего релиза](https://github.com/L1amqq/LM-WirelessRedstone/releases/latest) и поместите его в папку `mods`. Для совместной игры установите мод на сервер и клиенты. Для **Fabric** также нужен **Fabric API**.

Для Minecraft **1.21.11** нужна **Java 21**, для **26.1–26.3** — **Java 25**.

## Сборка

Запускайте Gradle на JDK 25. Для сборки под 1.21.11 также нужен JDK 21.

```powershell
# Windows
.\gradlew.bat release
```

```sh
# Linux / macOS
./gradlew release
```
